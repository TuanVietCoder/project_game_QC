## **🚀 HƯỚNG DẪN TẠO GOOGLE SHEET**

### **Bước 1: Tạo Sheet Mới**
1. Vào https://sheets.google.com
2. Click "New" → "Spreadsheet"
3. Đặt tên: "Ashfall Backlink Campaign Tracking"

### **Bước 2: Tạo Tabs**
Rename sheet mặc định và thêm tabs mới:
- Rename "Sheet1" → "YouTube Outreach"
- Add tab → "Review Sites"
- Add tab → "Communities"
- Add tab → "Weekly Traffic"
- Add tab → "Press Releases"
- Add tab → "Goals & Progress"

### **Bước 3: Copy Headers**
Copy dòng header từ templates trên vào mỗi sheet

### **Bước 4: Format Đẹp**
- Làm đậm headers (Ctrl + B)
- Highlight với màu (Format → Fill color)
- Freeze dòng đầu (View → Freeze → 1 row)
- Tự động điều chỉnh cột (Format → Column → Optimal width)

### **Bước 5: Thêm Công Thức**
**Tab "Weekly Traffic" - Tính tổng:**
- Column F (Total) = `=SUM(B:E)` cho mỗi hàng

**Tab "Press Releases" - Tính ROI:**
- Column H (ROI) = `=G/D` (Backlinks/Cost)

**Tab "Goals & Progress" - Tính % Progress:**
- `=B/A*100` để tính % của actual vs target

### **Bước 6: Share & Access**
- Click "Share" → Thêm email ai cần access
- Set quyền: "Editor" nếu cần chỉnh sửa, "Viewer" nếu chỉ xem
