# Ashfall — Tro Tàn

Trang web chính thức của **Ashfall** (Tro Tàn) — game soulslike pixel art cho di động, lấy kỹ năng làm trung tâm.

**Website:** https://ashfall.io.vn

## Về game

Ashfall là game soulslike mà **kỹ năng quyết định tất cả**. Không cày cuốc, không trả tiền để mạnh. Mỗi trận boss là một bài kiểm tra công bằng về khả năng đọc nhịp và phản xạ.

- **Thể loại:** Soulslike / Pixel art / Di động
- **Nền tảng:** iOS, Android
- **Engine:** Godot 4.3
- **Trạng thái:** Đang phát triển (đã có demo)
- **Studio:** TuanViet Studio

## Về repo này

Đây là mã nguồn trang web — HTML, CSS, JavaScript thuần, không có bước build.
Trang chạy trên GitHub Pages, nhánh `main`, thư mục gốc.

```
index.html          Trang chủ
map.html            Bản đồ thế giới
studio.html         Giới thiệu TuanViet Studio
tin-tuc*.html       Tin tức
blog*.html          Blog
assets/             CSS, JavaScript, ảnh
```

Tài liệu kiến trúc và tài liệu vận hành nội bộ không nằm trong repo công khai này.
